# Imágenes ilustrativas para eventos de desarrollo

Estas imágenes se integran como ejemplos del mapa de masi. No son fotos de los vecinos ni de sus coordenadas y no documentan emergencias actuales. Los autores y lugares originales no están asociados con los eventos ficticios.

Fuente: Pexels. [Licencia](https://www.pexels.com/license/). Uso dentro de la aplicación de demostración; no constituye una biblioteca de imágenes para redistribución independiente. El manifiesto guarda el origen y SHA256 de cada archivo. El seeder verifica su integridad y los recodifica como WebP sin metadatos.
